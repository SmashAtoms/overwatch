# Roadmap

## MVP

- Monorepo scaffold with Next.js web app, Fastify gateway, and FastAPI NLP mock service.
- Shared contracts, region config, renderer abstraction, and policy helpers.
- Mock aircraft, weather, ATC, scanner, camera, stack, and replay data.
- Local Docker stack for Postgres/PostGIS, Redis, MinIO, Prometheus, and Grafana.

## Phase 2

- Authorized live adapters for aircraft, weather, ATC, scanner, and camera metadata.
- Real replay persistence, clustering, and stack promotion logic.
- Airport-aware overlays, weather intersections, saved watch zones, and semantic transcript search.

## Phase 3

- Multi-receiver fusion, anomaly detection, collaborative annotations, subscriptions, and renderer expansion.
