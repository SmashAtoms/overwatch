# Permissions Matrix

| Source category | Default mode | Notes |
|---|---|---|
| Aircraft position | Enabled | Use approved APIs or operator-owned ADS-B inputs |
| Weather and alerts | Enabled | Public weather products with rate-limit compliance |
| Cameras | Link-only by default | Upgrade to embed only when terms explicitly allow it |
| ATC audio | Delayed / restricted | Authorized feeds only; no prohibited rebroadcast |
| Scanner audio | Delayed / restricted | Authorized or public sources only, with policy controls |
